# Lumira 한국어 영어 공통 서비스 구현

2026-10-18 · KR1-113 / KR1-625 / KR1-1146

## 사용자 요구와 구현 범위

모든 대화·서비스·콘텐츠에서 한국어와 영어를 지원한다. 사용자의 명시 선택을 우선하고 자동 모드에서는 현재 사용자의 발화와 대화 문맥으로 판단한다. 불명확하면 두 언어로 확인한다. 국적·얼굴·위치로 언어를 추측하지 않는다.

이번 변경은 공통 정책과 개발 서비스 구현이다. 클라우드/로컬 실제 STT·LLM·TTS 모델, 실제 음성 입출력, NAS와 T01 운영 배포는 본 변경으로 실행하지 않았다. `ko-KR`와 `en-US`를 기본 지원하며 en-GB 입력은 영어 그룹으로 정규화한다. 국가·시간대·서비스 권한은 언어와 독립적이다.

## 언어 결정 규칙

1. 확인된 사용자 선택 또는 완전한 전환 명령 → 해당 언어 고정. 자동 모드 복귀는 명시 설정한다.
2. 자동 모드 → 현재 화자의 최종 발화만 사용한다. 미완성 STT, 미디어/배경 음성은 무시한다.
3. 명확한 한국어/영어 발화 → 자율 선택·전환. 짧은 동의 응답은 현재 언어를 유지한다.
4. 숫자·이름만 있는 발화, 혼합 발화, 낮은 신뢰도 또는 근거 충돌 → 확인 질문. 답을 받기 전 서비스 진행을 보류한다.
5. 모르는 언어를 영어로 간주하지 않는다. 명시 locale 미지원은 거절한다.
6. `stop / 정지 / 멈춰`, `help me / 도와줘`는 언어 확인을 기다리지 않고 로컬 요청으로 전달한다. 실제 기기 정지 ACK 또는 보호자 전달 ACK를 대신하지 않는다.
7. 사용자/세션/turn/revision으로 이전 언어의 늦은 출력을 차단한다. 언어 전환은 동의·권한·과금·안전정책을 변경하지 않는다.

텍스트 판별은 보수적인 규칙 기반 휴리스틱이다. 음성 언어 판별 모델 자체가 아니다. 외부 LID score 기준 0.85와 margin 0.20은 개발 설정이며 실제 음성 데이터로 보정해야 한다. 외국어 인용·고유명사·억양·어린이 발화·잡음·혼합 발화는 실기 평가에 포함한다.

## 서비스별 연결

| 분야 | 적용 내용 | 코드 또는 후속 연결 |
|---|---|---|
| 사용자 프로필 | preferred_locale와 auto/fixed, 사용자별 세션 격리 | Kids 프로필 구현, 전체 프로필 저장소 연결 필요 |
| STT | 한국어·영어 탐지 결과와 최종 발화만 전달 | score 입력 계약 구현, 실제 STT 미연결 |
| 대화 | locale 포함 provider 요청, 명시 선택 우선, 오프라인/안전 안내 번역 | BilingualService 및 Epic-02 runtime |
| TTS·화면 | reply/ui/tts locale 통일, 지원 불일치 시 안내 | service_plan, 실제 voice ID와 UI 앱 연결 필요 |
| 교육·퀴즈 | 설명 언어와 learning_locale 분리, 정답·힌트·재시도 현지화 | Kids R3 |
| 이야기·역할 놀이 | 언어별 본문·선택 문구·종료 장면 | 한국어 200 + 영어 200 콘텐츠 레코드 |
| 음악·리듬 | 안내·쉼 표시 현지화, 원본 리듬 WAV 공유 | 100개 언어 중립 WAV, 음성/가창 생성 아님 |
| 생활교육 | 단계·완료 안내 현지화 | 한국어 300 + 영어 300 레코드 |
| Care·알림·보호자·커뮤니티 | 같은 locale 정책을 공통 계약으로 적용 | 각 실제 서비스 adapter 미연결; 완료로 표시하지 않음 |
| 콘텐츠 카탈로그 | 언어 필터, content_key로 번역판 연결, 검수 상태 보존 | Kids SQLite와 API 구현 |
| 운영 | 언어별 오류율·확인률·정정률·지연·콘텐츠 누락률 | raw 대화 로그를 지표로 저장하지 않음 |

## 콘텐츠 현황

별도 `Lumira_Kids_Bilingual_R3` 패키지는 KR1-1146에 첨부된 R2를 원본으로 사용한다. 한국어 1,300개를 보존하고 영어 교육용 현지화 버전 1,300개를 추가하여 2,600 레코드를 구성한다. 영어판은 기초 문장과 규칙 기반 변형을 포함한 교육용 각색이다. 1,300편의 독립 신규 작품 또는 전문 검수된 직역본이라고 주장하지 않는다. 일부 색 이름 과제 등은 영어 사용자에게 맞게 각색했다. 모든 레코드는 draft이며 기본 조회에서는 차단된다.

locale에 맞는 본문·정답·힌트·선택·생활 단계·리듬 안내를 제공한다. 없는 언어를 한국어로 조용히 대체하지 않는다. 언어 전환 중 진행 중인 활동은 중단하여 이전 질문을 다른 언어의 답으로 채점하지 않는다. 영어 학습 중 영어 정답을 말하는 것은 설명 언어 전환으로 처리하지 않는다.

## 재현과 검증

저장소 루트: `python Epic-02/runtime/run.py` (기존 132 + 신규 39 = 171 시험).
Kids 패키지 루트: `python -m unittest discover -s tests -v`.
Kids의 2,600 레코드 × T01/T10 = 5,200개 모의 실행, 1,592개 이야기 종료경로, 원본 보존, 언어 누락, 정답, DB 무결성, 보호자 권한, 실제 loopback API의 언어 전환을 검사한다. 보드 성능 측정과 물리 실행은 아니다.

## 실기 인수 항목

- 두 언어 실제 STT CER/WER, 언어 선택 정확도, 불필요한 전환 및 확인 질문 빈도.
- 로컬/클라우드 각각의 한국어·영어 대화와 TTS 가용성, 끊김/재연결 후 언어 유지.
- 화면 글꼴과 영어 긴 문구, 음성 길이에 따른 표정·동작 cue 재동기화.
- 사용자 전환, 미디어 음성, 한국어 설명+영어 학습, 끼어들기와 stop/help의 독립 처리.
- 각 서비스(가정·Elder·Kids·보호자·콘텐츠·커뮤니티)의 양언어 사용자 평가와 콘텐츠 전문 검수.
- RK3588 16GB, Pi 5 + HAT+ 26 TOPS, RK3576에 동일 시나리오 적용. 기존 30개 시험의 언어별 결과를 별도 기록한다.

실기와 운영 연결이 완료되기 전 전체 제품의 이중언어 서비스 출시 완료로 판정하지 않는다.
