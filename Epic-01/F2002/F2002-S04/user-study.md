# 사용자 검증·개선·재시험 계획

실사용 미수행. 고령자·보호자를 포함해 최소 10명 모집은 초기 제안이다. 실제 대상 집단과 최소 수·성공 기준은 연구 담당자/Q1/R1가 확정한다. 연구 설명·동의·철회·접근·보존 정책을 별도 보호 저장소에 보관하고 무작위 참가자 가명만 평가기에 입력한다.

과업: edit(호칭/언어/음량 등 수정), switch(본인/보호자 프로필 전환), reset(선호 초기화), revoke(선택 동의 철회), delete(삭제), resume(단절/재개). 도움 없이 실제 설정 효과를 확인하는지, 문구·가독성·음량·오류 복구·잘못된 사용자 전환을 관찰한다. 모든 과업을 연구에 포함하고 독립 완료 80% 이상을 제안한다. 평균 성공률만으로 삭제·동의·안전 결함을 통과시키지 않는다.

study 입력: participant_id 32자리 hex, task, mode(simulated/observed), version 0.1.0, completed(bool), assisted(bool), seconds(유한 0..86400). 이름/연락처/원문 추가 금지. 중복 참가자·과업·버전 기록 거부. 현재 evaluator는 v0.1.0만 받으므로 개선 후 새 후보의 재시험은 승인된 계약 확장이 필요하다. baseline·retest·문제/결함·수정 커밋·재검증 증적은 별도 보고서에 연결한다.

observed는 입력 라벨이며 진위·대표 집단·동의 증명이 아니다. 평가 출력은 제안 기준 충족 여부이며 Release 승인이 아니다. 실제 Q1/R1, 하드웨어·운영 승인 인터페이스는 미연결이다.
