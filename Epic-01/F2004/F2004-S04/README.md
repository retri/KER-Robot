# F2004-S04

Jira: https://lumira077.atlassian.net/browse/KR1-21

현재 수행 범위: 운영 지표·Release gate 초안; 실제 사용자 평가·운영 승인 대기

- 가족 사용자가 현재 활성 사용자를 알아볼 수 있게 표시하고 잘못 지정했을 때 쉽게 수정 가능한지 평가한다.
- 확인 요청률·수동 정정률·게스트 비율·전환 실패율을 집계하고 자동 식별 활성 기준을 결정한다.
- 등록·탈퇴·기기 공유 해제·생체 식별 동의 철회의 사용자 안내와 관리 절차를 정리한다.
- 자동 식별 기능에 문제가 발생하면 수동 선택만 남기는 기능 플래그 및 Rollback을 실행해 확인한다.

산출물: 가족 사용 안내, 식별 운영지표, 탈퇴·동의 철회 절차, 기능 플래그 및 Release Note.

완료조건: 가족 등록·전환·탈퇴가 끝까지 수행되고 자동 식별 중지 후에도 수동 개인화 기능이 정상 동작한다.

역할 제안(배정 변경 없음): R1 책임, R5 운영, R2 식별 평가

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
