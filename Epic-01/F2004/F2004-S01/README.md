현재 수행 범위: 설계 명세 작성

- 가족 구성원·게스트·보호자·관리자의 가입·탈퇴·공유 범위를 정의하고 공유 기억은 기본 비공유로 정한다.
- 후보 식별, 사용자 확인, Context 준비, 출력 중지·큐 비우기, 새 epoch 적용, 대화 재개의 전환 순서를 정의한다.
- 얼굴·음성 신뢰도와 확인 질문 기준을 시험 데이터에 따라 조정하도록 하고 사용자의 수동 선택을 우선한다.
- 자리 비움·동시 발화·미등록 얼굴·사용자 탈퇴·시간 초과의 게스트 복귀 규칙과 시험 케이스를 작성한다.

산출물: 가족·권한 모델, 활성 세션 스키마, 식별 후보 계약, 사용자 전환 상태표, 격리 시험 목록.

완료조건: 모든 전환 경로에 캐시·출력 큐 정리와 권한 재평가가 있고 불확실한 식별에 개인정보를 제공하는 경로가 없다.

역할 제안(배정 변경 없음): R1 설계 검토, R2 식별 정책, R5 세션

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
