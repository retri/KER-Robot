# F2004-S03

Jira: https://lumira077.atlassian.net/browse/KR1-20

현재 수행 범위: 자동화 시뮬레이션 시험; 실기 시험 대기

- A 대화 중 B가 선택하는 시험에서 A의 진행 중 TTS·기억 검색·제스처 요청이 취소되는지 확인한다.
- 유사 외모·다른 조명·동시 발화·사진 입력 등 후보 혼동 시험을 수행하고 결과를 권한 인증과 혼동하지 않는지 점검한다.
- 타인 ID 직접 조회, 탈퇴 사용자 토큰, 오래된 세션, 네트워크 지연 이벤트에 대한 격리를 검증한다.
- 여러 구성원이 같은 닉네임을 사용해도 내부 user_id로 분리되고 공유 허용되지 않은 기억이 반환되지 않는지 시험한다.

산출물: 사용자 전환·유출 시험, 혼동 행렬과 조건별 식별 결과, 큐 취소 증적, 결함 재시험.

완료조건: 시험 집합에서 사용자 간 정보 노출 0건이며 불확실 후보는 확인 또는 게스트로 처리된다. 전환 실패가 개인 정보 노출로 이어지지 않는다.

역할 제안(배정 변경 없음): Q1 검증, R2·R3·R5 조치

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
