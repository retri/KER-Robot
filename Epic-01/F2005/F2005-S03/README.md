현재 수행 범위: 자동화 시뮬레이션 시험; 실기 시험 대기

- 모델별 동일 질문과 동일 선호를 실행하여 응답 내용·화면·음성·제스처 제한의 차이를 확인한다.
- Kids에서 보호자 미승인 설정 변경, Care에서 승인되지 않은 건강 콘텐츠, Pet에서 미지원 동작을 차단하는지 시험한다.
- 정책 전환 중 재부팅·패키지 손상·동시 사용자 전환·동의 철회를 주입하고 안전한 정책으로 복귀하는지 확인한다.
- 외부 알림·기관 서비스가 없을 때 기능 비활성 또는 실패 안내가 표시되고 수행한 것처럼 응답하지 않는지 검증한다.

산출물: 모델별 회귀시험, 정책 충돌·손상·복구 결과, 외부 서비스 실패 시험, 안전 출력 증적.

완료조건: 모델별 필수 케이스 전부 통과하고 정책 변경으로 동의·권한·기기 상한이 완화되는 사례가 없다.

역할 제안(배정 변경 없음): Q1 검증, R2·R3·R5 조치

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
