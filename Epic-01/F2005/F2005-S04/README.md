# F2005-S04

Jira: https://lumira077.atlassian.net/browse/KR1-26

현재 수행 범위: 운영 지표·Release gate 초안; 실제 사용자 평가·운영 승인 대기

- 모델별 대표 사용자 또는 현장 담당자의 평가를 수행하고 공통 코어와 모델 특화 설정을 구분하여 개선한다.
- 모델별 오류율·금지 기능 차단·정책 버전 분포·복귀 횟수를 집계하고 콘텐츠 운영 담당을 정한다.
- 기기별 설치 정책, 승인자, 변경 이유, 시험 결과를 Release Manifest에 기록한다.
- Stage 1 공통 코어 출시와 모델별 출시 게이트를 따로 관리하고 미검증 모델은 비활성화 상태로 배포한다.

산출물: 모델별 사용 안내·평가, 정책 운영 가이드, 승인 기록, Release Manifest 및 Rollback 절차.

완료조건: 출시할 모델마다 인수 기록이 있고 미승인 모델·콘텐츠가 실제 기기에서 선택되지 않는다.

역할 제안(배정 변경 없음): R1 책임, R2 콘텐츠 운영, R5 배포

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
