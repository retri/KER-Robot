# F2005-S02

Jira: https://lumira077.atlassian.net/browse/KR1-24

현재 수행 범위: 로컬 핵심 로직 Prototype

- 버전 관리된 정책 패키지와 검증기를 구현하고 승인되지 않은 필드·모드·테마 조합을 차단한다.
- 기기 기능·사용자 권한·동의·모델 정책을 합성하는 Policy Resolver와 정책 변경 Preview를 구현한다.
- 정책 적용을 prepare·validate·commit 순서로 수행하고 관련 모듈 ACK 누락 시 이전 정책으로 복귀한다.
- 5개 제품 코드의 샘플 정책을 만들고 스키마·무결성·미지원 버전 거절을 구현한다. 샘플 해시만으로 승인이나 배포자 인증을 증명하지 않으며 운영 서명키·배포 승인은 별도 연동한다.

산출물: Model Policy Service, 정책 파일·검증기, 샘플 패키지, 적용·복귀 Prototype.

완료조건: 5개 모델 샘플의 허용·차단 결과가 기능표와 일치하고 잘못된 정책은 적용되지 않는다. 승인 서명 검증은 운영 키 연결 후 별도 증적을 남긴다.

역할 제안(배정 변경 없음): R5 주도, R2 정책 콘텐츠, R3 표현 제한

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
