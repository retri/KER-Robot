현재 수행 범위: 설계 명세 작성

- Friend·Kids·Care·Home·Pet의 필수·선택·제외 기능과 모델 SKU·UI·콘텐츠 매핑표를 정의한다.
- 제품 모델·상호작용 모드·테마의 우선순위와 충돌 해결 규칙을 정의하고 실제 예시를 작성한다.
- 모델별 콘텐츠 허용 목록, Quiet Hours, 보호자·기관 관리자 권한, 오프라인 허용 기능을 스키마로 표현한다.

산출물: 모델별 기능표, 정책 스키마, 권한·충돌 규칙, 콘텐츠 승인 절차, 모델별 인수시험.

완료조건: 모든 기능 플래그에 허용 모델·권한·오프라인 동작이 지정되고 공통 코어와 모델별 출시 범위가 검토된다.

역할 제안(배정 변경 없음): R1 제품 정책, R2 콘텐츠·대화, R5 정책 구조

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
