# 사용자·검토자 안내

사용자는 본인/보호자/게스트를 선택하고 언어, 호칭, 목적, 표현 선호, 선택 동의를 확인한다. 선택 동의를 거부해도 정상 경로이며 게스트의 개인정보 관련 권한은 꺼져 있다. 내용을 검토한 뒤 등록한다. 저장 완료와 로봇 이용 준비는 다른 상태이므로 장치 적용이 끝날 때까지 기다린다. 연결이 끊기면 진행 상태를 확인해 재개하고, 오류가 반복되면 도움을 요청한다. 원하지 않으면 취소하고 설정·동의 변경은 승인된 서비스 화면에서 수행한다.

S04는 별도 사용자 등록 UI를 제공하지 않는다. S02 UI 및 기존 서비스는 유지하며 S04 계측 API 연결은 운영 통합 과제다. 개발 검토자는 README의 명령으로 Dashboard를 열고 simulated 라벨, 기간·분모·버전, 오류·Release 차단 목록을 확인한다. 운영자는 원본 사용자 DB나 키를 결과 파일에 첨부하지 않는다.
