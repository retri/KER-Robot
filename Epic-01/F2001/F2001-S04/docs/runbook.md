# 운영 대응 절차

현재 운영 기준 및 모니터링 연결은 미승인이다. Dashboard는 생성 시점 스냅샷이다.

| 신호 | 초기 대응 | 재개 조건·기록 |
|---|---|---|
| 로그 유실 dropped_events > 0 | 저장 공간·권한·DB 연결 조사, 누락 기간 표시, 지표 신뢰성 보류 | 수집 정상화·누락 범위·담당자·Jira 증적 |
| 적용 실패 증가 | 새 등록 완료와 장치 ready 구분, 실패 모듈 확인, 제한된 재시도 | S03 안전 게이트·멱등 ACK 통과, 실패율 재확인 |
| 중복 등록 | 신규 Release 보류, 키·트랜잭션 재현, 결함 등록 | 중복 제거 승인·재시험; 자동 삭제 금지 |
| 장치/네트워크 단절 | 안전한 출력 정지 및 상태 안내, 저장 상태 확인 | 소유권·연결·중복 출력 확인 후 재개 |
| 개인정보 사고 | 원문 추가 기록 중단, 접근 제한, 담당 운영자에게 내부 절차로 인계 | 승인된 사고 대응·키 교체·감사 절차 |
| 배포 후 회귀 | 신규 후보 중단, 승인된 복귀 절차 수행 | 최신 철회/삭제 원장·진행 상태 보존·실기 확인 |

지원 기록에는 가명·버전·단계·허용된 오류 코드·증적 링크만 남긴다. 대응 시간/SLO/연락망/로그 보존/경보 임계치와 소유자는 실제 운영 데이터·담당자 승인으로 확정한다. 이 프로그램은 알림을 전송하거나 장치를 제어하지 않는다.
