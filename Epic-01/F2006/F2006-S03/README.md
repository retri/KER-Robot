# F2006-S03

Jira: https://lumira077.atlassian.net/browse/KR1-30

현재 수행 범위: 자동화 시뮬레이션 시험; 실기 시험 대기

- 호칭·말속도·대화 길이·제스처 선호 조합별 대화와 실제 표현을 대조한다.
- 응답 생성 중 단절, 늦은 클라우드 응답, TTS 오류, 사용자 변경을 주입하고 발화·동작 취소를 시험한다.
- 불확실한 감정·틀린 기억·지원하지 않는 요청에서 확인·정정·한계 설명이 이루어지는지 평가한다.
- Quiet Hours 및 사용자 종료 요청이 proactive greeting보다 우선하고 위험한 제스처 ID가 차단되는지 확인한다.

산출물: 대화 품질 평가, backend 전환·중단 시험, 표현 동기화 증적, 정책 준수 및 안전 시험.

완료조건: 필수 대화 시나리오 전부 수행되고 중복 발화·타인 정보·승인되지 않은 동작 실행이 없다.

역할 제안(배정 변경 없음): Q1 검증, R2 품질, R3·R5 조치

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
