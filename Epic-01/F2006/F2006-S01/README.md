# F2006-S01

Jira: https://lumira077.atlassian.net/browse/KR1-28

현재 수행 범위: 설계 명세 작성

- 인사·경청·회상·이야기·종료의 대화 목적과 정상·예외 대본을 작성하고 사용자 대상별 허용 표현을 정한다.
- 사용자 선호·확인 기억·현재 감정 관찰을 Context에 넣는 순서를 정의하고 정보가 없을 때 확인 질문을 사용한다.
- idle, listening, thinking, speaking, paused, ending 상태와 사용자 끼어들기·종료·Quiet Hours 전이를 정의한다.
- 클라우드 timeout, 로컬 fallback, 뒤늦은 클라우드 응답 폐기 기준 및 turn_id 멱등 규칙을 정의한다.

산출물: 동반자 대화 정책·시나리오, 상태 전이표, 응답 계획 계약, backend 전환·중단 시험 기준.

완료조건: 모든 발화에 종료·중단 경로와 backend 실패 경로가 있고 기억 근거·감정 불확실성의 표현 기준이 결정된다.

역할 제안(배정 변경 없음): R2 설계, R1 검토, R3·R5 인터페이스

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
