# F2006-S04

Jira: https://lumira077.atlassian.net/browse/KR1-31

현재 수행 범위: 운영 지표·Release gate 초안; 실제 사용자 평가·운영 승인 대기

- 사용자 평가에서 자연스러움·호칭 정확성·말속도·중단 편의성을 확인하고 과도한 선제 대화를 줄인다.
- 대화 성공률·사용자 중단률·fallback 비율·중복 응답·표현 오류를 집계하고 원문 로그는 별도 선택 동의를 적용한다.
- 대화 정책·Prompt·모델·표현 카탈로그의 버전을 묶어 운영하며 문제가 있는 조합을 비활성화한다.
- 로컬 기본 인사·종료·설정 안내는 클라우드 장애 때도 유지하도록 배포·복귀 절차를 작성한다.

산출물: 사용자 대화 평가, 정책·Prompt 버전 목록, 운영 Dashboard 정의, 배포·복귀 안내.

완료조건: 장애 시 기본 대화가 유지되고 정책 버전 되돌림 후 사용자 선호·기억 권한이 보존된다.

역할 제안(배정 변경 없음): R1 책임, R2 대화 운영, R5 배포

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
