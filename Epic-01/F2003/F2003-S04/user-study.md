# 실제 사용자 검증·개선·재시험 계획

현재 실사용 미수행·인정 참가자0명. 합성 데이터/개발자 fixture는 실제 연구가 아니다. 연구 담당자는 대상 집단·참가자 수·독립 수행/품질 기준·동의·철회·보존·접근권한을 Q1/R1와 확정한다. 고령자/보호자 상황과 제3자 앞 발화를 검토한다.

과업: remember 요청, confirm 저장 후보 확인, recall 회상, correct 정정, delete 개별/전체 삭제, revoke 동의 철회, switch 사용자 전환, offline 이용. 저장 정보 이해·정정/삭제 통제·자연스러움·잘못된 회상·과도한 기억 활용·원치 않는 발화·도움 요청을 관찰한다. 개인정보/권한/삭제 정보 부활은 평균 점수와 무관한 차단 결함이다.

study는 가명32hex·task·mode(simulated/observed)·version0.1.0·completed/assisted bool·유한seconds만 받는다. 중복 참가자/과업/버전 거부, 합성 제외, 실제 참가자/관찰수·독립 성공률만 산출한다. observed 라벨의 진위·동의·대표집단을 자동 인증하지 않는다. 임계치는 승인되지 않았으며 study_acceptance는 pending이다.

별도 보호 보고서에 baseline 문제·결함·수정 커밋·승인된 후보의 retest·증적 위치를 연결한다. 현재 version/phase 모델을 넘어서는 다중 라운드는 승인 후 계약 확장이 필요하다. 연구 원문/연락처/민감 기억 내용은 공개 GitHub/Jira/Artifact에 올리지 않는다.
