# F2007-S03

Jira: https://lumira077.atlassian.net/browse/KR1-35

현재 수행 범위: 자동화 시뮬레이션 시험; 실기 시험 대기

- 터치·호출·칭찬·놀이 입력을 실제 장치에서 시험하고 센서 노이즈와 반복 입력을 주입한다.
- 무음 설정·Quiet Hours·사용 시간 종료·사용자 변경·모드 변경 중 진행 동작의 취소를 확인한다.
- 고장 센서의 이벤트 폭주, 누락 에셋, 지원하지 않는 동작 ID를 주입하여 정지 또는 기본 표정 복귀를 시험한다.
- 의상과 팔·목의 간섭 위험은 R6·R3 검토 결과에 따라 동작 허용 목록에서 제거하고 실기 증적을 남긴다.

산출물: 상태·센서·에셋 오류 통합 시험, 반복 자극 부하시험, 중단·안전 동작 증적.

완료조건: 이벤트 폭주가 과도한 출력으로 이어지지 않고 사용자의 중단과 안전 제어기가 모든 반응을 선점한다.

역할 제안(배정 변경 없음): Q1 검증, R2·R3·R4·R6 조치

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
