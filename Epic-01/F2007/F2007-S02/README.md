# F2007-S02

Jira: https://lumira077.atlassian.net/browse/KR1-34

현재 수행 범위: 로컬 핵심 로직 Prototype

- Pet 상태기계와 이벤트 정규화 어댑터를 구현하고 중복 event_id 및 너무 오래된 이벤트를 폐기한다.
- 표정·소리·제스처 카탈로그를 로드하고 동작별 기기 capabilities와 모델 정책을 검사한다.
- 타이머 기반 휴식 복귀와 자극 반복 cooldown, 사용자 선호에 따른 표현 강도 변환을 구현한다.
- 동반자 모드와 Pet 모드 전환 시 출력 큐를 정리하고 새 epoch의 상태로 초기화한다.

산출물: Pet Engine, 이벤트 어댑터, 캐릭터 에셋 패키지, 시뮬레이션·실기 실행 안내.

완료조건: 정의한 상태 전이가 자동 입력으로 재현되고 반복 입력에도 동작 큐와 음량이 제한 범위를 넘지 않는다.

역할 제안(배정 변경 없음): R2 주도, R3 출력, R4 입력, R5 패키지

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
