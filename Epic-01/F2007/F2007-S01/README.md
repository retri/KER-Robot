현재 수행 범위: 설계 명세 작성

- 캐릭터 정체성·표정·소리·놀이 레퍼토리를 정의하고 제품 모델별 선택 가능 범위를 정한다.
- 상태×이벤트 전이표와 이벤트 우선순위, 연속 터치 debounce·cooldown, 휴식 복귀 조건을 작성한다.
- 실제 센서와 가상 입력을 같은 이벤트 계약으로 연결하고 이벤트 시간·중복·늦은 도착의 처리 규칙을 정한다.
- 음량·표정 강도·제스처 제한과 사용시간·Quiet Hours를 적용하는 위치 및 인수시험을 정의한다.

산출물: Pet 캐릭터 명세, 상태 전이·이벤트표, 콘텐츠 카탈로그, 안전·중단·반복 입력 시험.

완료조건: 모든 이벤트에 반응·무시·중단 기준이 있고 사용 제한과 비상정지의 우선순위가 명시된다.

역할 제안(배정 변경 없음): R2 캐릭터·상태 설계, R3 동작, R4 센서
