Jira: https://lumira077.atlassian.net/browse/KR1-36

현재 수행 범위: 운영 지표·Release gate 초안; 실제 사용자 평가·운영 승인 대기

- 사용자 평가로 캐릭터 반응의 이해도·반복 피로·접촉 방식·휴식 안내를 확인한다.
- 이벤트별 반응 성공률·cooldown 비율·모드 종료율·에셋 오류율을 수집하고 개인 대화 내용은 수집하지 않는다.
- 캐릭터 사용 안내와 모드 종료·기본 모드 복귀 방법을 작성하고 콘텐츠 승인자를 지정한다.
- 에셋·상태기계·동작 카탈로그를 묶어 버전 관리하고 손상 패키지 복귀 및 이전 캐릭터 복원을 시험한다.

산출물: 캐릭터 사용 가이드, 평가·운영지표, 콘텐츠 승인 목록, Release Note 및 에셋 Rollback.

완료조건: 사용자가 중단·전환·재시작할 수 있고 에셋 복귀 후 승인된 캐릭터 반응이 재현된다.

역할 제안(배정 변경 없음): R1 책임, R2 캐릭터 운영, R5 배포

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
