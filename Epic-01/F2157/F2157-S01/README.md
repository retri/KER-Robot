현재 수행 범위: 설계 명세 작성

- 의상↔테마 매핑과 승인 절차를 정의하고 NFC UID 복제·읽기 실패·태그 충돌의 처리 기준을 정한다.
- 의상 착용·제거 감지 방식을 실물 구조에 맞춰 선택한다. presence TTL·debounce·센서 장애 복귀 시간은 시험 가능한 설정값으로 둔다.
- 테마 Manifest, 패키지 무결성, 호환성·모델·사용자 선호 충돌 규칙과 기본 Persona를 정의한다.
- 팔·목·통풍·카메라·마이크 간섭을 R6·R4와 검토하고 의상별 금지 동작 및 발열 관련 제한을 기록한다.

산출물: 의상·테마 매핑, NFC·제거 감지 계약, Theme Manifest, 원자적 적용 상태표, 실물 간섭 검토.

완료조건: 모든 승인 의상에 기본 복귀 경로와 허용 동작표가 있으며 감지 실패·부분 적용 시험이 설계된다.

역할 제안(배정 변경 없음): R2 총괄, R4 NFC, R6 의상, R3·R5 계약

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
