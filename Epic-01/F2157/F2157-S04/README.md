# F2157-S04

Jira: https://lumira077.atlassian.net/browse/KR1-41

현재 수행 범위: 운영 지표·Release gate 초안; 실제 사용자 평가·운영 승인 대기

- 사용자가 테마 변경·음성 고정·복귀를 이해하는지 평가하고 알림·미리보기·변경 취소를 보완한다.
- 의상 감지 실패·미등록 ID·모듈 준비 실패·기본 복귀·패키지 오류를 집계하고 태그 값을 사용자 정보와 함께 기록하지 않는다.
- 승인 의상·기기 버전·테마 패키지·허용 동작을 Release Manifest에 묶고 지원하지 않는 조합을 차단한다.
- 테마 기능을 원격 비활성화하거나 패키지를 이전 버전으로 되돌릴 때도 기본 Persona와 사용자 선호가 유지되는지 시험한다.

산출물: 의상 사용·등록 안내, 호환성·승인표, 운영지표, Release Manifest, 비활성화·Rollback 절차.

완료조건: 의상 제거·테마 기능 비활성화·이전 버전 복귀가 재현되고 기본 대화·표정·안전 제어가 계속 동작한다.

역할 제안(배정 변경 없음): R2 원본 책임, R1 출시 검토, R5 운영

자동 시험은 `Epic-01/integration/run.py`에서 수행한다. 시험 환경은 개발용·단일 프로세스이며 실제 장치의 출력 취소나 안전성 증거를 대신하지 않는다.
